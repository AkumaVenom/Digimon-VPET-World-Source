# Digimon-VPET-World-Source

Digimon VPET World

Functional open source unreal engine project of Digimon VPET World, an Unreal Engine source-based fan project inspired by classic Digimon virtual pets, modern Digimon games, built entirely in 3D anime-style cel-shaded graphics, with 3D Digimon & optional 2D animated Digimon sprites rendered inside a 3D world

The project is designed as a playable Digimon sandbox focused on exploration, wild battles, scanning & materialization, feeding mechanics, and long-term expansion.

Engine & Compatibility

Primary Engine Version: Unreal Engine 4.27

Tested & Working: Unreal Engine 5.5 with some adjustments applied.

Project Type: Full source project (GitHub-ready)

Rendering Style: Anime-style cel shading (3D), optional 2D animated Digimon sprites

⚠️ While UE5.5 is supported, the project is configured for UE4.27 by default for maximum stability.

--------------------------------------------------------------------------------------------------------------------------------------------------------------

Buttons

F Key: Actions

TAB: Options Menu

Left Mouse Button: Command Player Owned Digimon To Attack Enemy Digimon

Scan & Materialization System

Inspired by Digimon Story: Cyber Sleuth

Winning battles grants Digimon Scan Data (%)

Once Scan Data reaches 100%, the Digimon can be materialized

Encourages repeated encounters and progression

--------------------------------------------------------------------------------------------------------------------------------------------------------------

Digimon can be fed

After eating, Digimon will:

Later poop directly in the world

At the exact location they were standing

True virtual-pet style care mechanics

--------------------------------------------------------------------------------------------------------------------------------------------------------------

Seed-Based World Selection

Levels are entered via a seed typing system

Each seed selects a pre-made level

The system visually simulates:

Typing into a HTTPS website

Entering that “website” as a level

A unique diegetic UI approach to level selection
